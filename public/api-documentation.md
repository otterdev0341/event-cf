# Voice Confirm — การเชื่อมต่อ API

ตั้งค่าการเชื่อมต่อ Voice Bot ของคุณก่อนเลือก Agent หรือทดสอบโทรจริง

## ขั้นตอน

1. สร้างแคมเปญและอัปโหลด CSV
2. จับคู่คอลัมน์หมายเลขโทรศัพท์ (phone) และตัวแปรบทสนทนา
3. เลือก Agent ที่โหลดจากบัญชีของคุณ
4. กดทดสอบการเชื่อมต่อ ระบบตรวจบัญชีด้วย GET /me แล้วตรวจคู่สายของบัญชีนั้น
5. หากต้องการโทรทดสอบ ให้ระบุเบอร์ของคุณและยืนยันการโทรก่อนกดปุ่ม

การบันทึกแคมเปญเป็นการเก็บฉบับร่างในเบราว์เซอร์ การโทรอัตโนมัติและการตั้งเวลายังต้องเชื่อม backend เพิ่ม

รายละเอียด API สำหรับนักพัฒนาอยู่ใน docs/API_DOCUMENTATION.md ของ repository
