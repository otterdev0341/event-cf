# โทรเฉพาะรายชื่อและประวัติการโทร

ในหน้าโทรตาม CSV เลือก "เลือกเฉพาะบางคน" แล้วติ๊กแถวที่ต้องการ เลือกข้ามหน้าได้ ก่อนเริ่มจะแสดงจำนวนคนที่จะดำเนินการ หากต้องการโทรคนที่จบสายแล้ว เปิด "โทรซ้ำรายชื่อที่เลือกและจบสายแล้ว" และยืนยันจำนวนอีกครั้ง สายเดิมและผลเดิมยังอยู่ในประวัติ

คิวตรวจสายที่ยังทำงานต่อโดยไม่ส่งซ้ำ และใช้ข้อมูลจากแถว CSV ที่บันทึกบนเซิร์ฟเวอร์ ตรวจเฉพาะแถวที่เลือก รหัสคำขอของสายแรกคงรูปแบบเดิม ส่วนโทรซ้ำอ้างอิงคำขอก่อนหน้าที่จบสายแล้วและใช้รหัสคงที่ เพื่อให้การส่งซ้ำจากอีกแท็บไม่โทรซ้ำโดยไม่ตั้งใจ เซิร์ฟเวอร์ตรวจประวัติล่าสุด บัญชี และรหัสคำขอก่อนจองคำขอ คิวนี้ยังต้องเปิดหน้าและให้เครื่องทำงานไว้

ตารางหลัก ยอดสรุป และผลล่าสุด CSV ใช้คำขอล่าสุดต่อแถว CSV ของแคมเปญเวอร์ชันปัจจุบัน เลือกตามเวลาเริ่มคำขอ ไม่ใช้เวลาแก้ผลหรือเวลา callback สายเก่า หากคำขอใหม่ยังไม่มีผล จะแสดงรอตรวจสอบโดยไม่ยกคำตอบเดิมมาใช้ ข้อมูลทุกครั้งยังอยู่ในฐานข้อมูล ปุ่มประวัติของแต่ละแถวแสดงทุกครั้งเรียงล่าสุดก่อน พร้อมเปิดรายละเอียดของครั้งนั้นได้ มุมมองประวัติทุกสายและประวัติ CSV รวมสายจากเวอร์ชันเก่าด้วย

ประวัติแต่ละครั้งมีปุ่มฟังเสียงของสายนั้น หน้าแคมเปญแสดงเฉพาะไฟล์ที่บริการระบุเชื่อมกับ Call ID หรือรหัสเชื่อมที่ได้รับยืนยันแล้ว ไม่แสดงรายการไฟล์รวมของ Agent ส่วนผลตอบรับจาก Tool การตรวจผลด้วยตนเอง และประวัติทุกสายยังแสดงตามเดิม ดูสัญญารับรหัสไฟล์จาก Botnoi ที่ [BOTNOI_RECORDING_CALLBACK.md](BOTNOI_RECORDING_CALLBACK.md)

หน้าบันทึกผลด้วยตนเองใช้ผลตอบรับและความต้องการเจ้าหน้าที่เท่านั้น ไม่มีช่องข้อความที่ได้ยินหรือเหตุผลประกอบ API ไม่บังคับข้อความประกอบสำหรับผลที่ผู้ใช้ตรวจแล้ว และเก็บข้อความเดิมไว้เมื่อไม่ได้ส่งฟิลด์นี้ ผลจาก Tool ยังคงตรวจสอบข้อความประกอบตามเดิม
