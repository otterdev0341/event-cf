# โทรเฉพาะรายชื่อและฟังบันทึกเสียง

ในหน้าโทรตาม CSV เลือก "เลือกเฉพาะบางคน" แล้วติ๊กแถวที่ต้องการ เลือกข้ามหน้าได้ ก่อนเริ่มจะแสดงจำนวนคนที่จะดำเนินการ หากต้องการโทรคนที่จบสายแล้ว เปิด "โทรซ้ำรายชื่อที่เลือกและจบสายแล้ว" และยืนยันจำนวนอีกครั้ง สายเดิมและผลเดิมยังอยู่ในประวัติ

คิวตรวจสายที่ยังทำงานต่อโดยไม่ส่งซ้ำ และใช้ข้อมูลจากแถว CSV ที่บันทึกบนเซิร์ฟเวอร์ ตรวจเฉพาะแถวที่เลือก รหัสคำขอของสายแรกคงรูปแบบเดิม ส่วนโทรซ้ำอ้างอิงคำขอก่อนหน้าที่จบสายแล้วและใช้รหัสคงที่ เพื่อให้การส่งซ้ำจากอีกแท็บไม่โทรซ้ำโดยไม่ตั้งใจ เซิร์ฟเวอร์ตรวจประวัติล่าสุด บัญชี และรหัสคำขอก่อนจองคำขอ คิวนี้ยังต้องเปิดหน้าและให้เครื่องทำงานไว้

ตารางหลัก ยอดสรุป และผลล่าสุด CSV ใช้คำขอล่าสุดต่อแถว CSV ของแคมเปญเวอร์ชันปัจจุบัน เลือกตามเวลาเริ่มคำขอ ไม่ใช้เวลาแก้ผลหรือเวลา callback สายเก่า หากคำขอใหม่ยังไม่มีผล จะแสดงรอตรวจสอบโดยไม่ยกคำตอบเดิมมาใช้ ข้อมูลทุกครั้งยังอยู่ในฐานข้อมูล ปุ่มประวัติของแต่ละแถวแสดงทุกครั้งเรียงล่าสุดก่อน พร้อมเปิดรายละเอียดและตรวจเสียงของครั้งนั้นได้ มุมมองประวัติทุกสายและประวัติ CSV รวมสายจากเวอร์ชันเก่าด้วย

ในรายละเอียดสาย กด "ตรวจ / โหลดบันทึกเสียง" เรียก GET `/workspace/calls/<request_id>/recording` เซิร์ฟเวอร์ตรวจเจ้าของคำขอ บัญชี Voice Bot เดิม และ Call ID แล้วค้นหาไฟล์ที่เชื่อมกับสายอย่างชัดเจน ไม่มีการจับคู่ด้วยเวลา ชื่อ หรือ Agent เพียงอย่างเดียว ใช้ `/logs/audio_url?file_path=...` ตาม API ของ Voice Bot เพื่อรับลิงก์เสียง หากมีเครื่องเล่นจะแสดงบนเว็บ ไม่เล่นอัตโนมัติ

ลิงก์เสียงไม่เก็บลงฐานข้อมูลและอาจหมดอายุ กดตรวจใหม่ได้ หากบริการไม่มีไฟล์ แสดงข้อความตามจริง ไม่สร้างเสียงจำลอง การบันทึกเสียงต้องมีอยู่บน Voice Bot ก่อน เว็บนี้ไม่ได้เปิดการบันทึกหรือสร้างไฟล์เสียงจากข้อความผลตอบรับ
